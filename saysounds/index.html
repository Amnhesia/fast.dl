¿Cómo creo el token? (una sola vez)
  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta Amnhesia.
  2. Nombre: saysounds. Caducidad: la que quieras.
  3. Repository access → Only select repositories → fast.dl.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate token, cópialo y pégalo aquí.

El token solo puede tocar el repo fast.dl. No lo compartas: quien lo tenga puede subir y borrar sonidos.
